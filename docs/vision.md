# 项目愿景

ComfyUI-Aaalice-Workflow-Hub 是 ComfyUI 内的双向工作流中心：作者在插件里发布，订阅者在插件里发现、查看并下载不同版本。

## 目标

- 让工作流、版本、说明、更新日志和依赖声明形成可校验的公开协议。
- 让一个仓库承载多个可独立发布、下载和归档的工作流产品。
- 让所有节点环境变更先形成计划，再由用户确认并交给 ComfyUI-Manager。
- 让发布和下载失败有可定位的原因，已发布 Release 与已下载旧版本不被覆盖。

## 1.0 边界

1.0 已实现公共 GitHub 仓库订阅、GitHub Device Flow、Release 直接发布、目录更新、安全包下载、历史版本保留、节点依赖计划、双语界面和用户隔离存储。

1.0 不包含私有仓库、其他 Git 服务、模型自动扫描或下载、任意节点 Git 地址、遥测、侧边栏和 Comfy Registry 发布。ComfyUI 自身在工作流加载时仍负责缺失模型提示。

## 原则

- 工作流产品是核心对象，仓库只是发布载体。
- 订阅不等于下载，下载不等于修改节点环境。
- 发布版本不可覆盖；展示资料和归档状态可以更新。
- 能取得下载字节时才展示百分比，其他阶段展示真实阶段与日志。
- 不执行仓库或工作流包中的脚本，不把模型或第三方节点代码装入工作流包。
