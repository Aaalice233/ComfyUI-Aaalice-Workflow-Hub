# 1.0 功能与状态

本文件描述仓库当前实现。规划外能力不会在界面中伪装成可用。

## 已实现

### 顶栏和内置页面

- Frontend `actionBarButtons` 注册顶栏按钮，最低 Frontend `1.33.9`。
- 普通点击在 ComfyUI 内使用非全屏面板加载 `/workflow-hub`；面板不重复创建外层标题栏，关闭入口位于工作流中心自身顶栏；`Shift+点击` 打开独立窗口。
- 工作流中心采用黑灰桌面工作台布局：顶栏以居中 Switcher 切换订阅和发布，滑块、页面动效与强调色同步变化；订阅使用蓝色强调色，发布使用粉色强调色。
- 界面语言自动跟随 ComfyUI 的 `Comfy.Locale` 设置；简体及繁体中文使用中文界面，其余 ComfyUI 语言使用英文界面。
- ComfyUI 启动后在后台按 ETag 检查订阅源；已有工作流出现更高版本时，合并显示一个 5 秒自动关闭的 ComfyUI 内置 Toast，同次服务运行中每位用户只提示一次。
- 订阅页以搜索和筛选为主入口，订阅源按需展开管理。
- 工作流卡片和详情页可直接打开 GitHub 原始仓库；详情页可切换历史版本、查看当前版本变更记录，并跳转对应的 GitHub Release 页面。
- 详情页采用紧凑的项目摘要、版本导航和单版本工作区；封面仅作缩略图，历史版本不再纵向重复展开，空资源以计数呈现。
- 未登录时发布页只显示 GitHub 授权引导，不读取仓库或展示发布表单；登录后自动读取当前画布，并在一个页面内完成仓库、类别、名称、版本、更新日志和资源确认。
- Vue 3、TypeScript、Vite 源码和生产构建产物同时交付。

### 订阅和下载

- 添加、刷新和移除公共 GitHub 订阅源。
- ETag 缓存；页面启动检查一次，也支持手动刷新，不常驻轮询。
- 聚合目录、搜索、下载/更新/归档筛选、详情和历史版本。
- 下载 GitHub Release 包并验证 HTTPS 主机、大小、SHA-256、ZIP 条目、路径、符号链接、压缩比和解压总量。
- 每个版本写入独立文件；同版本文件内容不一致时报完整性错误。
- 已下载版本可从详情页直接在系统文件管理器中打开其所在目录。
- 读取目录时核对已下载记录与本地文件；文件被用户从 ComfyUI 或资源管理器删除后，失效记录自动清理。
- 移除订阅不删除已下载文件；本地版本只能由用户明确删除。

### 发布

- GitHub App Device Flow 登录：授权页分两步突出显示验证码和 GitHub 入口，验证码支持一键复制，授权完成后自动进入发布界面；凭据使用 keyring/session 降级存储。
- 发布器仅使用当前 ComfyUI 画布，不提供文件选择器；页面顶部持续显示捕获到的工作流文件名，避免误发其他工作流。
- 发布流程改为单页双栏发布控制台，不再使用步骤条；仓库、类别、名称、版本和更新日志集中编辑，底部发布操作持续可见。
- 发布页右侧资源检查台按节点依赖、随包图片和 LoRA 分类切换并使用紧凑清单展示；订阅详情页按版本展示已发布的三类清单及数量，旧目录缺少图片清单时显示为空。
- 仓库选择会保存在浏览器本地；再次打开发布页时优先恢复上次选择。仓库名称、作者和说明直接读取 GitHub，不要求重复填写。
- 仓库目录使用单层 `category`；发布器读取仓库现有类别，也允许直接输入新类别，不提供树形嵌套。
- 工作流 ID 由名称自动生成；发布已有工作流时从仓库目录中选择，以保持 ID 稳定。
- 发布器不再提供封面上传；旧目录中的 `cover` 和 `preview` 仅作为兼容数据显示。
- 校验版本、自动生成的稳定 ID、Release tag、清单和依赖声明。
- 创建 Draft Release、上传 ZIP、发布 Release，再以文件 SHA 条件更新目录。
- 目录并发冲突重新获取并合并一次；Release 已发布而目录同步失败时记录待同步数据，续传不重复创建 Release。

### 依赖与安全

- Registry 依赖与手动依赖分开声明。
- 依赖计划状态：`keep/install/upgrade/newer/conflict/unknown/manual`。
- `newer` 默认保留；手动依赖和冲突不会自动执行。
- 节点环境变更必须二次确认，并串行提交给 Manager。
- Manager 不可用时仍允许下载工作流。
- 自动扫描并打包 `Load Image` 节点引用的本地图像，安装时写入隔离的 ComfyUI input 子目录并改写引用。
- 随包图片同时写入版本目录的 `inputs` 字段，使订阅用户无需下载 ZIP 即可确认图片名称、大小和引用节点。
- 识别 Lora Manager 引用；作者可逐项选择独立发布 LoRA，或一键清空待发布工作流中的 LoRA 引用。
- 独立发布的 LoRA 是可选资源，订阅用户必须逐项主动下载，绝不随工作流自动下载。
- 写接口限制同源、JSON Content-Type、2 MiB 请求体和当前 ComfyUI 用户。
- 操作日志脱敏，不包含遥测。

## 不在 1.0 范围

- 私有 GitHub 仓库、GitLab、Gitee 或任意资源主机。
- 覆盖/删除已发布 Release 资产。
- 自动下载模型或 LoRA。
- 执行工作流仓库脚本。
- 自动安装、升级、降级、启用节点。
- Comfy Registry 发布或自动发布流程。
