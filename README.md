# Aaalice Workflow Hub

一个仍处于规划阶段的 ComfyUI 工作流管理插件。

它的目标是让用户订阅工作流仓库，在 ComfyUI 内查看工作流列表、版本更新和更新日志，并按需下载不同用途的工作流。后续还计划提供可审查的依赖版本对齐与安装进度。

目前仓库只完成了项目初始化，尚不可用于生产环境，也暂未提交到 Comfy Registry。
